## 📖 Overview

The **LSDAC ICT Duty Rota System** is a responsive web application designed to coordinate sound engineering, video switching, PTZ camera operations, EasyWorship visuals, stage acoustics, and live streaming for worship services across September, October, and November 2026.

---

## 🛠️ Key Features

- **📊 Full Schedule Roster Matrix**: Mirroring the official church media roster with 44 registered participants across 13 Sabbaths.
- **📱 Mobile-First Responsive Design**: Optimized for smartphones with thumb bottom-bar navigation and collapsible Sabbath cards.
- **⚡ Add Week & Smart Auto-Assignment**: Easily add consecutive Sabbath weeks with automated fair-share role rotation that checks skills, workload balance, and member leave dates.
- **🔒 Admin Mode & Coordinator PIN**: Role-based access control protecting schedule edits, week deletion, member management, and swap approvals (Default PIN: `7777`).
- **🔄 Duty Swaps & Cover Desk**: Self-service cover request workflow for team members who are traveling or unavailable.
- **📲 WhatsApp Broadcast Generator**: Formats 1-click ready-to-paste WhatsApp messages with emojis, duty breakdown, and reporting times.
- **📅 Export Hub**: iCal (.ics) calendar sync, printable bulletin sheets, and CSV database archives.

---

## 👥 Official Booth Roles

1. 🔊 **Audio Console** — Front-of-House digital audio mixing, preacher mics, choir balance.
2. 🎬 **Video Switcher** — ATEM/vMix/OBS switching, lower thirds, stream cuts.
3. 🎥 **Camera Operator** — PTZ camera controls, pulpit tracking, framing.
4. 📽️ **Presentation** — EasyWorship hymnal, scripture readings, sermon slides.
5. 🎤 **Stage Audio** — Stage monitors, wireless handheld mics, pulpit audio.
6. 🌐 **Online Stream** — YouTube/Facebook stream health and chat moderation.
7. 📺 **Confidence Monitor** — Stage speaker timers and lyric prompts.
8. 📻 **Overflow AV** — Overflow tent sound and video relay.

## 🚀 Getting Started

### Prerequisites
- Python 3.8+ (Zero extra dependencies required)

### Running the Local Server
```bash
# Navigate to project directory
cd "LSDAC_ICT Duty Rota"

# Run server
python server.py
# or on Windows
py server.py
```
Open **`http://localhost:8080`** in your browser.
